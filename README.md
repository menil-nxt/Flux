# What is use of "ReportWebVitals.js"

it is use for measure and reportyour application's performance in the brower.

it contains 4-5 performance metrics.

1. CLS (cumulative layout shift) - measures unexpected movement of page element.
2. INP (interaction to next Paint) - measures how responsive the page feels to user interactions.
3. FCP (first contentful paint) - measures how long it's takes for the first text or image to appear.
4. LCP (Largest contentful paint) - measures how long it takes for the man visible content to appears.
5. TTFB (Time to first Byte) - measures how long it takes to receive the first byte of a response.
